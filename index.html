FAQ

Questions, answered

Which course should I start with?

If you build Android apps today, start with Android Architecture Mastery. Then go to Offline-First Android App to add sync and your own Ktor backend. When you're ready for iOS and Desktop, take Compose Multiplatform: Build Gamopedia. Not sure? Take the 30-second quiz above.

What do I need to know before starting?

The basics of Kotlin and Android development. The multiplatform courses are easier if you already know Jetpack Compose.

Do I need to know Swift or have a Mac?

No Swift needed: the multiplatform UI is written in Compose. You only need a Mac to run the iOS app. Android, Desktop and the Ktor backend work on Windows, macOS and Linux.
